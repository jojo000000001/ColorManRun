# 镜面实现与调节

## 场景布置

沿用 Built-in 渲染管线，不安装额外渲染包。使用反射相机、RenderTexture 和 `ColorManRun/PlanarMirror` Shader，实现角色、跑道、旋转终点及天空盒的动态倒影。

第一关采用两个有边界的水平镜面，而非将一个无限镜面挪上挪下：

- `MirrorGround`：y=-4，覆盖 z=-180 到 220。
- `MirrorGround_Lower`：y=-24，覆盖 z=220 到 760，对应 y=-20 的粉色段。

跑道厚度约两米，因此镜面位于跑道底部下方约两米。上层镜面在粉色段起点截断，避免盖住低处跑道；交界处是两个固定高度的台阶边界，不会追随玩家突然改变倒影高度。镜面边缘做三米透明渐隐，减轻硬边。

第二关基础跑道仍在 y=0，仅放一个 y=-4 的 `MirrorGround`，覆盖 z=-180 到 760；空中平台自然使用同一镜面反射，无需按平台颜色另分镜面。

三块镜面均在已有的 MirrorGround Layer 上，无 Collider、TrackPart 或 Rigidbody，不提供地面支撑，不改变掉落、颜色死亡或通关逻辑。原来第一关的白色镜面占位平面已复用。

## 运行方式

`Assets/Scripts/Camera/PlanarMirror.cs` 绑定各场景的 PlayerFollowCamera。在主相机开始剔除前渲染倒影，因此跟随与跳跃不会使倒影滞后一帧。反射相机不自动渲染、不带 AudioListener；排除所有 MirrorGround 和 UI Layer，并使用重入保护防止递归。

通过反射矩阵翻转视图及剔除方向，通过倾斜裁剪平面排除镜面下方几何。Shader 使用投影坐标采样，处理纹理方向与摄像机倾斜。每块镜面用独立 MaterialPropertyBlock，既共享材质，又不会互相覆盖纹理。

仅对主相机可见且相机位于其正面的镜面更新。默认纹理宽 512、高按相机宽高比计算；同一尺寸反复复用，不逐帧分配。第一关交界处可能同时产生两次额外渲染，第二关通常一次。禁用、切场景、重开或脚本重载时释放自建相机和纹理；异常时也恢复全局剔除设置，不修改项目灯光质量设置。

## 调节入口

- 镜面高度、位置、覆盖范围：场景中的两个 MirrorGround 对象；Unity Plane 原始边长 10 米，Scale.x/z 分别控制宽度和长度。
- 清晰度：各对象 PlanarMirror 的 Texture Size（512 可改为 1024；清晰度越高额外开销越大）。
- 反射对象：Reflection Mask；必须保留 Ground、Player 及角色视觉对象所用的 Default 层。
- 颜色、强度、边缘渐隐：`Assets/Materials/PlanarMirror.mat` 的 Reflection Tint、Reflection Opacity、Boundary Fade。
- 补装：`Tools > ColorManRun > Install Planar Mirrors`。已有 PlanarMirror 的对象不会重复配置，以保留手调参数。

## 验证

`Tools > ColorManRun > Run Planar Mirror Checks` 在独立临时场景中进行实际渲染与像素回读。35 项通过：0/-20 高度、0/13 度相机倾斜、反射位置与纹理方向、动态物体同次渲染更新、下方红色物体被裁剪、排除镜面、纹理复用、全局状态恢复、禁用释放及再次启用。

另已检查第一关上层、低处粉色段、跨层交界和第二关的主相机画面。编辑器验证不等于独立构建性能验收；目标硬件帧率及其他图形 API 仍需在构建后复核。
