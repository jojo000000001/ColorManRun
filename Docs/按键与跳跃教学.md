# 按键与跳跃教学

两个场景的 `PauseCanvas/KeyboardHints` 固定在右下角，使用 UI 中的 ButtonLeft、ButtonUp 图片。它们只是键盘提示，不接收点击或触摸，不改变输入逻辑。

第一关在 `JumpTutorialHud` 的 Tutorials 中直接绑定两个黑块的 Collider：

- TrackBeam_Black：轻按 ↑ 跳跃。
- TrackBeam_Black Long：长按 ↑ 跳得更远。

变色慢动作教学绑定下方长条粉色跑道 `TrackBeam_Pink 1`，不再绑定前方橙色平台 `TrackBeam (4)`。Lead Seconds 为 0，进入粉色跑道的 Z 范围后显示“左键变颜色”，角色在空中时使用现有减速倍率，落地恢复。移动、缩放粉色跑道后触发范围随 Collider 更新，无固定世界坐标判断。

后半段三处异色衔接分别绑定下一段跑道 `TrackBeam (6)`、`TrackBeam_Pink_Nomal`、`TrackBeam (7)` 的 Collider。提示为两行“尝试跳起来 / 并在空中切换颜色”，“跳起来”使用橙色 `#FFA500`，“切换”使用粉红色 `#FF69B4`，其余保持白色，同时轻微强调两个按键。Lead Seconds 为 1.5，End After Front Meters 为 8：提前显示，越过下一段前沿 8 米后淡出，避免持续整段跑道挡住下一处教学。新增提示不启用慢动作，每局每处一次，重开可再次提示。后续移动跑道时，衔接提示跟随 Collider 前沿。

每条的 Lead Seconds 默认 1.5。只在 Playing 状态下，当角色距 Collider 世界包围盒前沿的 Z 距离不大于“角色整帧实际 Z 位移 / 帧时长 × Lead Seconds”时显示。速度 20 时提前约 30 米。首次尚无移动样本时回退到 baseSpeed；不直接读取 CharacterController.velocity，以免角色多次 Move 的子步移动使速度被低估。提示持续到玩家位置越过后沿，再用 0.2 秒淡出；无超时。跳跃图标轻微呼吸强调。

暂停冻结提示与动画，恢复不重置；死亡、通关立即隐藏；重开每条可以重新触发。同一局不重复触发，出生点后方已越过的黑块不会补播。第二关只显示常驻按键，无教学点。

调整位置：按键编辑 `PauseCanvas/KeyboardHints` 的 RectTransform；教学文字编辑 `PauseCanvas/JumpTutorial` 的 RectTransform，独立锚定在屏幕下方中央（1920×1080 参考分辨率下位置为 10、160）。调整提前量或更换黑块：编辑 JumpTutorialHud 的 Tutorials。运行时不根据物体名称查找黑块，不使用 PlayerPrefs。

中文字体运行时优先使用 Microsoft YaHei / Noto Sans CJK SC / SimHei，目标机器需有支持中文的字体；如需在无系统字体的平台发行，应另行打包授权字体。

验证入口：Tools → ColorManRun → Check Keyboard Tutorials (Edit Mode)。安装工具仅用于首次搭建，对已有 KeyboardHints 不重复安装，不会自动运行。
