# 音乐与音效

两关场景均放置 `Assets/Prefabs/MusicManager.prefab`。运行时保留一个跨场景的 MusicManager，场景重开不会叠加播放。资源通过 Inspector 序列化引用绑定，不在运行时按文件路径加载。

## 文件与触发条件

- `Bgm.wav`：SampleScene 第一关循环背景音乐。
- `bgm2.wav`：Level2 第二关循环背景音乐；直接从第二关运行同样生效。
- `run.flac`：实际移动且着地时循环；离地、静止、暂停、死亡、通关时停止或暂停。
- `jump.flac`：监听 PlayerController.JumpStarted，仅成功起跳时播放，包含普通跳、长跳和二段跳。按住不重复播放，长跳托举不额外播放。
- `crash.flac`：GameManager 首次进入 Dead 时播放一次。不改变死亡或重开流程；独立的持久音源使约 0.73 秒音效不会被 0.5 秒自动重开截断。
- `stand2.flac`：暂按“落地”解释，从空中转为着地时播放一次；出生时不播放。文件名语义不明确，可在 MusicManager 的 Landing 字段替换。

未提供独立的变色或通关音效，因此没有复用不相关音效。终点旋转体逻辑保持不变。

## 配置与行为

在 MusicManager Prefab 的 Inspector 调整音量：Music 0.35、Run 0.25、Action 0.7、Crash 0.8。BGM、跑步、动作和死亡分别使用独立的 2D AudioSource；无需随距离衰减。有效 AudioListener 沿用 PlayerFollowCamera，不新增监听器。

只有 Playing 播放关卡音乐；逻辑暂停暂停所有管理器音源，恢复后继续原进度。同关死亡重开继续原 BGM，换关更换曲目。教程慢动作不改变音高或音乐速度。

BGM 使用 Streaming，短音效使用 Decompress On Load 并预加载。`Tools > ColorManRun > Install Music Manager` 可为缺少管理器的两关补装，已有实例和 Prefab 的手动配置不会被覆盖。

## 回归入口

- Edit Mode：`Tools > ColorManRun > Check Music Configuration`，检查两关引用、音源和监听器。
- 暂停的 Play Mode：`Tools > ColorManRun > Check Music Runtime (Paused Play Mode)`，同步检查事件、播放、暂停、落地、死亡与关卡曲目。测试后退出 Play Mode 恢复关卡；测试不会保存场景。

自动检查验证状态和资源绑定，不替代对音色、响度、跑步节奏的实际试听。

本次验证：24 项配置检查、19 项音频运行时检查通过；真实切换 Level2 保留同一管理器并播放 bgm2，第二关死亡自动重开后 crash 仍在播放。Unity Console 无编译错误。

额外运行旧的 PlayerRegressionChecks 时，“长跳后二段跳取消助推并保留前进倍率”断言未通过。关闭 MusicManager 后同样失败：旧断言期待 longJumpSpeedMul，而当前角色代码明确保持倍率 1。这是现有角色实现与旧断言不一致，本次未修改角色代码或放宽断言。
