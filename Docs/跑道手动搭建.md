# 跑道手动搭建（Prefab + SO）

不再依赖名为 `LevelRoot` 的节点。它之前只是起点、终点和跑道的组织容器，不是跑道必须依赖的运行组件。

## 使用方式

1. 从 `Assets/Prefabs` 拖入 `TrackBeam` 或 `TrackBeam_Pink`，保留 Prefab 连接。
2. 在实例的 `TrackPartBinding / Definition` 中指定 `Assets/SO` 下的跑道配置。
3. SO 提供 `Length`（长度，米）、`Thickness`（厚度，米，默认 0.4，最小 0.01）和 `Color`（Yellow / Pink / Black）；修改后已加载场景中的绑定对象会自动刷新，运行时也会应用配置。
4. 手动移动或旋转实例。网格的 Pivot 位于起点顶面，因此 Position.y 就是顶面高度；位置不会被 SO 重置。
5. 需要不同长度/厚度/颜色组合时，复制 SO 并重命名，或右键 Create → 跑酷 → 跑道长条配置。再把新 SO 指定给目标实例。
6. 保存场景和 SO。可用任意空物体归组，但父级缩放应保持 `(1,1,1)`。

## 注意事项

- 绑定后，根节点 Scale 由脚本控制：宽度固定 3 米，长度和厚度按 SO 设置；不要再手动拉伸 Scale。旧 SO 的厚度默认保持 0.4 米。
- 厚度从顶面向下延伸，网格和碰撞体一起缩放，不修改实例 Position；水平放置时顶面高度保持不变。
- 同一 SO 是共享配置。修改它会影响所有引用者；不想批量修改就先复制 SO。
- 修改长度不会自动移动其他长条或终点。下一段起点 Z = 本段起点 Z + 本段长度 + 缺口宽度（沿 +Z、无旋转时）。
- 跑道的 Collider 必须在 Ground 层，且不能勾 Is Trigger。预制体已设置 Ground，现有碰撞体形状保留。
- `TrackPart` 负责角色颜色判定和 MaterialPropertyBlock 显色；有绑定时只在 SO 中修改颜色，不再另改 Color Index 或材质。
- `TrackBeam_Black` 是保留的旧预制体，已添加绑定入口，但不默认分配 SO；可手动绑定 `Track_Black` 或其他 SO。
- 黑色的跑道颜色索引是 2，黄色/粉色仍是 0/1。角色仍只切换原来的两色；黑色不自动成为安全/中立跑道，踩上黑色仍按现有颜色不匹配规则失败。
- 起点和终点仍需按新布局手动摆放，终点保留 `FinishTrigger` 和 Trigger Collider；去掉 LevelRoot 不等于去掉通关触发器。
- `Tools/生成测试跑道` 现在指向基于 SO 的可选批量工具，不再创建旧 Cube 跑道。日常手动搭建无需使用此入口。

## 当前场景检查提示

当前两个活动长条的起点仍为 Z=0 和 Z=55，绑定的默认 SO 长度为 14 米；因此它们之间有约 41 米的视觉缺口，并非可直接试玩的最终布局。需要按跳跃能力手动调整间距。本次不自动移动已有实例、角色或摄像机。
