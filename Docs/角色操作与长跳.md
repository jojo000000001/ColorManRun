# 当前角色操作与长跳

- 空格：按下立即普通跳；落地缓冲、土狼时间及空中一次二段跳均按新的按下操作处理。
- 上方向键短按（未到 0.2 秒松开）：松开时请求普通跳。
- 上方向键：按下立即普通跳，与空格的响应时机一致；继续按住达到 `0.2s` 后，将本次上跳升级为长跳。松开不会再触发第二次跳跃。
- 长跳成功后继续按住上方向键：最多助推 `0.25s`；松开、达到最大上升速度、开始下落或撞顶可提前结束，不会每帧重新设置起跳速度。
- 左方向键：切换颜色并播放转身，原有颜色冷却和判定保持不变。

## 二段跳

普通跳、长跳之后，在空中重新按下空格或上方向键，可额外跳一次。二段跳将竖直速度重设为共享 SO 的 **Jump Velocity**，不是叠加速度；上升中和下落中均可使用，不提供持续助推。长跳后二段跳会取消本次长跳助推，但保留长跳前进倍率直到落地。

只有真实脚底支撑恢复时才补充空中跳次数，平台侧面、撞顶、暂停恢复或组件禁用重启不会补充。直接走落平台也可空中跳一次；土狼时间内的普通跳不占用空中跳次数。没有落地记录的空中出生角色不能直接获得二段跳。

必须有新的按下操作，持续按住不自动二段跳。空中没有二段跳次数时，空格和上方向键都只设置普通落地缓冲，不会成长跳；普通落地缓冲不会自动消费二段跳次数。每帧最多成功起跳一次，每次成功的二段跳沿用 `JumpStarted` 动画事件。

## 死亡后自动重开

掉落到失败高度或颜色不匹配时，角色停止，默认等待 `0.5s` 后重新加载**当前关卡**，回到该场景保存的 Player 初始位置并自动奔跑。第二关死亡仍重开第二关；只有通关才切换到下一关。

位置、速度、长跳助推、按键缓冲、变色冷却、颜色、动画和相机随场景重新初始化，关卡计时归零。不会保留死亡前的错误颜色或空中状态，也不修改共享运动 SO。关卡中的其他运行时变化同样会重置。

每关 GameManager 的 **Restart Delay** 可调整等待时间，设为 `0` 时下一帧开始重载；重复死亡判定不会重复安排重开。场景必须已保存并加入 Build Settings（现有两关均已配置）。

## 共享调参入口

统一修改 `Assets/SO/SharedPlayerMovement.asset`。SampleScene 与 Level2 的 PlayerController → **Movement Settings** 引用同一资源，读取时不复制参数，因此改一次即可同步两关（包含切关后）。新建关卡也要绑定此 SO。

当前共享资源调参：前进速度 `20`、重力 `-20`、普通跳初速度 `10`、长跳初速度 `10`、长跳前进倍率 `1.45`、掉落失败高度 `-40`。土狼时间 `0.08s`、输入缓冲 `0.1s`、长按阈值 `0.2s`、变色冷却 `0.35s` 也统一由 SO 管理。

角色半高、脚底中心偏移、Ground Mask、材质调色板和相机目标仍属于各场景/模型，不放进 SO。当前速度、颜色、按键消耗标记及计时器也不放进 SO，避免角色之间串状态。未绑定 SO 的旧场景保留旧参数兼容，并在运行时提示 Warning。

注意：运行模式中直接修改 SO 资源可能保留到退出运行后；正式调参建议退出 Play Mode 后修改并保存资源。运动代码只读配置，不写入 SO。

## 助推参数

共享 SO → **Long Jump Hold Acceleration**：当前 **18**（单位/秒²）。

共享 SO → **Long Jump Max Hold Time**：当前 **0.25**（秒）。从实际成功起跳计时，不包含起跳前 `0.2s` 的长按识别等待；设为 `0` 禁用持续助推。

共享 SO → **Long Jump Max Upward Speed**：当前 **18**（单位/秒）。这是助推的速度上限，不是世界坐标高度，也不是加速度数值上限。

长跳助推期间，竖直加速度为 `gravity + longJumpHoldAcceleration`，仍按已有小步积分更新速度和位置。当前两关均为 `-20 + 18 = -2`，不能依靠速度上限及时终止助推。因此新增时长上限，到期后恢复为 `-20`。松开或到期不清零向上速度，角色仍会自然上升一段距离，随后减速下落，不设硬性位置/高度截断。

到期、松开、达到速度上限、到达最高点/开始下落或撞顶后，**本次助推永久结束，后续仅受重力，继续按住也不重新助推**。若时长、最高点或速度边界落在积分子步内部，剩余部分使用正常重力，避免额外整帧助推。撞顶仍由控制器清零向上速度以阻止穿透。

速度上限仅限制助推产生的上升速度，不影响普通跳。若长跳初速度本身已达到或超过上限，则该跳不再助推，也不会强行截断初速度；速度上限设置为 `0` 同样禁用持续助推。

## 边界规则

- 只有实际成功起跳的长跳获得助推；普通跳、空中失败的跳跃请求、直接走出边缘均不获得助推。
- 普通跳保留 `0.1s` 输入缓冲和 `0.08s` 土狼时间；空格和上方向键按下时立即执行普通跳。
- 上方向键在地面或有效土狼时间起按后持续至 `0.2s`，会把当前起跳升级为长跳；仅在角色仍上升时升级。空中没有二段跳次数时，上方向键与空格一样进入普通落地缓冲，不会执行长跳。
- 一帧最多实际起跳一次，空格优先；同帧按下空格和上方向键不会连跳。持续按住不会自动二段跳或在落地后重复起跳。
- 松开后在空中重新按住，不恢复上一跳的助推，也不会空中重新起跳。
- 落地、非 Playing 状态及组件禁用时取消助推；暂停后不会遗留按住状态。
- 暂停、死亡、通关、组件禁用及新场景均清空待处理跳跃；恢复时已经按住的跳跃键必须先松开后再按。
- 自动前进、长跳前进倍率和落地颜色判定仍沿用现有实现；每次实际成功起跳仅发送一次动画事件（二段跳也发送）。

## CharacterController 与终点判定（2026-10-26）

两关玩家已改为 `CharacterController.Move` 扫掠移动，不再使用 Rigidbody + Trigger 胶囊或直接写 Transform 来驱动位移。重力、起跳速度、小步积分和助推继续读取原共享 SO，未修改其数值。胶囊半径 `0.4m`、半高 `1m`、中心偏移 `(0, 0.79, 0)`；控制器坡度上限 `50°`、台阶高度 `0.3m`、Skin Width `0.02m`。Animator Root Motion 关闭。

地面探测使用近脚底的 `SphereCastNonAlloc`（球形扫掠，不是单条 Raycast），只认可有效坡度的支撑表面，排除初始重叠的零距离命中；平台侧面不算落地。颜色死亡检查除脚底支撑外，还由 `CharacterController.OnControllerColliderHit` 检查角色胶囊与有色 `TrackPart` 的任何实际碰撞，因此空中擦到错误颜色平台的侧面或底面也会死亡。上升时不吸附地面；落地颜色判断先于消费普通跳缓冲。

每关 `FinishTrigger` 显式绑定最后一块安全平台的实际 BoxCollider 和玩家。终点区宽度收至平台宽度、高度 `2.5m`，贴在末段平台上方；平台和终点的前后位置不变。只有玩家落稳在绑定平台上、颜色正确、胶囊水平截面完全位于平台内部且脚底进入终点区，才提交通关候选。空中、下方、侧缘接触均不能通关。候选在本帧移动与死亡判定结束后复核，同帧死亡优先，仍按原流程立即加载下一关，不新增结算等待。

## 回归检查

进入 Play Mode 后点击编辑器 Pause，再执行菜单 `Tools > ColorManRun > Run Player Regression Checks (Paused Play Mode)`。检查创建临时隔离对象，直接驱动输入状态机并调用真实控制器碰撞，不模拟系统键盘、不修改共享 SO、不保存场景。结束后退出 Play Mode 恢复关卡。

检查覆盖跳跃输入、二段跳次数与落地恢复、缓冲/土狼时间、助推时长/速度上限、松开/最高点/撞顶终止、持续按住的完整跳跃、暂停/死亡/禁用清理、支撑颜色优先级、墙面/侧面、43.54° 上下坡和终点死亡优先。参数边界测试使用共享 SO 的内存副本，不污染正式资源。检查结果和数量以运行输出为准；这些检查不替代全程手动游玩与构建验收。
